# Gario Chatbot: Multi-Shot Context and System Prompts

## What is Multi-Shot Context?

**Multi-shot context** is a technique used to guide AI models by providing multiple examples. This helps the model generate more consistent and goal-oriented responses. Each example teaches the model how to respond appropriately in similar situations.

With this method:
- The tone and style of the conversation can be established,
- The user's previous requests are considered,
- Contextual continuity is maintained.

In advanced chatbot systems like Gario, storing previous interactions allows multi-shot context to be applied effectively.

## What is a System Prompt?

A **system prompt** is an initial instruction given to an AI model that defines its general behavior throughout a conversation. It shapes how the model responds in terms of tone, style, and perspective.

Through the system prompt:
- The personality of the model is defined (formal, friendly, academic, etc.),
- The approach to the topic is guided,
- Language usage and communication style are controlled.

In Gario chatbot, the system prompt helps ensure consistent responses that align with the desired tone and functionality.

## Application in Gario Chatbot

In systems like Gario, using system prompts and multi-shot context together ensures:
- Continuity of the dialogue,
- Consistency in the model’s personality and response style,
- More accurate and context-aware outputs.

Typically, the system prompt is set at the beginning, and each new user message is passed along with previous messages to maintain context. This results in more natural and fluent conversations.

## Conclusion

- **System prompt** defines how the model behaves.
- **Multi-shot context** provides examples to guide the model.
- Together, they allow chatbots like Gario to deliver more intelligent, coherent, and personalized responses.
